# Claude 娘桌宠 · claude-desk-pet

一个给 [Claude Code](https://claude.com/claude-code) 用的小插件：Claude 干活的时候，桌面上会有一个 Q 版 Claude 娘陪着你，实时显示它在做什么。

![六种状态预览](docs/preview.png)

## 功能

**🧡 桌宠悬浮窗**：透明背景、永远置顶，可以拖到屏幕任何位置

| Claude 在做什么 | 桌宠的样子 |
|---|---|
| 思考中 | 闭眼想事情，"思考中…" |
| 跑命令、改文件 | 敲键盘，气泡里显示正在改哪个文件 |
| 读文件、搜索、上网查 | 捧着书记笔记 |
| 回复完，等你说话 | 敲门："轮到你啦！" |
| 出错 | 慌张冒汗 |
| 被你打断 | 心虚 |
| 干了 3 分钟以上的大活 | 撒花庆祝 🎉 |
| 等你超过 10 分钟 | 开始发呆 zZ |

还有一个彩蛋：连续出错 3 次会……石化 🗿

- **双击**桌宠：把 Claude 窗口叫到前台
- **右键**菜单：调大小（小/中/大）、切到 Claude 时自动隐藏、提示音开关、退出

**📊 Token 状态栏**：输入框下方常驻一行用量信息

> 📊 本会话 输入 12.3k · 输出 4.1k · 缓存命中 87% · $0.42 · 上下文 31% · 5h额度 23%

**🔔 提示音**：回复完播放钢琴"叮咚"，出错播放复古 RPG"哔哔"

**🚶 走来走去，坐在你的窗口上**：她是桌面上一个有"脚"的角色，窗口的顶边和屏幕底边都是她的地板

- 她会跟着你当前用的窗口：坐在它的顶边上看着你；你切到别的窗口（稳定不到 1 秒的路过不算），她就跳过去；拖动、缩放窗口，她跟着走
- **你可以随时把她拎起来**，放到哪里都行：松手后她会自己落下去，停在下面第一块地板上（任何窗口的顶边，或者屏幕底边），不会再自己跑回去。这时「自动跟着当前窗口」会暂停，在右键菜单里重新勾上，她才会再去当前窗口
- 她站着的窗口被关掉、最小化了，她会掉下去
- 坐着的时候大部分时间是静静的，只是偶尔晃一会儿腿；闲着的时候偶尔在窗口顶边上溜达几步
- Claude 在思考、读文件的时候，她托腮看着；在改文件的时候，她也敲起键盘；回复完先站起来敲门，再坐下
- 出错、被打断、干完大活撒花的时候，她会站起来；站起来、坐下去时会轻轻蹦一下
- 窗口顶边上方要有足够的空间才坐得下（大号要约 500 像素，小号约 300 像素，4K 屏幕按 150% 缩放算）；"自动跟着"时放不下的话（最大化、贴着屏幕上沿），她就站在屏幕底边，只在这个窗口的左右范围内走动
- 提醒休息的时候，她走到窗口中间来找你
- 不喜欢的话，右键关掉「跟着窗口走动」，她就回到老样子：固定在桌面一角，可以随便拖（`settings.json` 里是 `roam`；`follow` 是"自动跟着当前窗口"）

**⏰ 休息提醒**：连续工作到点了，她会提醒你休息；不理她，就越催越急

| 阶段 | 什么时候 | 她的样子 |
|---|---|---|
| 温柔 | 连续使用 50 分钟 | 端着茶杯挥手 |
| 催促 | 再过 10 分钟没理 | 双手合十求你 |
| 急了 | 再过 10 分钟没理 | 叉腰鼓腮跺脚，之后每 5 分钟再催一次 |

- 按键盘鼠标有没有动来算"在工作"，离开电脑超过 5 分钟就当你休息过了，自动重新计时
- 提醒的时候**点她一下**，或右键选「我去休息了」，就重新计时
- 晚上 23 点到凌晨 5 点，台词会变成催你睡觉
- 右键菜单里可以开关、选间隔（30 / 45 / 50 / 60 / 90 分钟），还有「试一下提醒」不用等就能预览
- 想细调，改 `~/.claude/desk-pet/settings.json`：`breakWork`、`breakEscalate`、`breakRepeat`、`breakAway`（单位都是分钟），`breakEnabled`（true / false）

**命令**

- `/token-stats`：查看本会话和本项目累计的 token 用量、缓存命中率、额度
- `/pet`：不小心关掉了桌宠？用它重新召唤

## 运行要求

- **Windows**（悬浮窗和提示音用的是 Windows 的接口）
- **Python 3**，并且在命令行里输入 `python` 能直接运行
- **Pillow** 图像库，用下面这条命令安装：

```bash
pip install pillow
```

## 安装

**在终端里的 Claude Code**，输入：

```
/plugin install desk-pet --marketplace BingXing-ai/claude-desk-pet
```

然后按 `y` 添加插件市场，选择 user（用户）范围，按回车确认。

**也可以在命令行里运行：**

```bash
claude plugin install desk-pet --marketplace BingXing-ai/claude-desk-pet
```

**在 Claude 桌面端**：点输入框旁边的 **+** → **Plugins** → **Add marketplace**，填入 `BingXing-ai/claude-desk-pet`，再点 **Add plugin**。

装好后，新开一个会话，桌宠就会出现在屏幕右下角。

## 自定义

- **换立绘**：把 `pet/sprites/` 里的 PNG 换成你自己的图（透明背景，文件名保持不变）
- **换提示音**：替换 `sounds/done.wav`（完成）和 `sounds/error.wav`（出错）
- **改台词**：气泡里的文字写在 `hooks/register.ts` 里

桌宠的位置、大小和开关保存在 `~/.claude/desk-pet/settings.json`。
